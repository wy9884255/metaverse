# Metaverse · 1:1 本星系群与银河太阳系实时天体物理渲染引擎

基于纯 **WebGL2 / GLSL ES 3.00** 多重通道体渲染（Raymarching）与开普勒星历构建的 **1:1 真实物理比例跨 18 数量级宇宙可视化与科普视频渲染引擎**（零外部贴图与第三方引擎依赖，单文件离线可运行）。

## 核心入口文件

- **`solar_system_1to1.html`**：**1:1 本星系群全成员 · 大小麦哲伦星系 (LMC/SMC) · 仙女座大星系群 & 银河太阳系** 独立离线单文件版（可直接双击打开，或通过 GitHub Pages / 任意静态服务器在线运行，支持一键导出 60 FPS 高清 MP4 素材）。
- **`index.html`**：宇宙视角科普分集演示主入口。
- **`src/`**：模块化源码、GLSL 着色器组件（广义相对论黑洞、类地/气态行星与卫星、大小麦哲伦星云与本星系群矮星系体渲染）及独立单文件打包脚本 `build_solar_standalone.py`。

1. **太阳系与近邻恒星系**：太阳黑子/米粒组织/日冕、八大行星及主要卫星（地球双层气象锋面云与城市夜光、阿波罗地出、木星大红斑与伽利略卫星凌木影、土星扁球与卡西尼环缝、天王星/海王星 2024 真彩等）、4.2465 光年比邻星系统（Proxima b / d）与南门二双星。
2. **银河系、银心黑洞与六大传奇名星/星云**：
   - Gaia DR3 / Spitzer 27° 棒旋结构、四主旋臂与三维暗尘埃消光带、银心 S 星团轨道，以及 **人马座 A\* (`Sgr A*`)** 弯曲时空广义相对论吸积盘与引力透镜双拱光环。
   - **六大 1:1 银河系传奇天体**：**红超巨星参宿四 (`Betelgeuse`, $764\,R_\odot = 3.55\text{ AU}$ 沸腾超羽流与大变暗尘埃云)**、**天狼星双星 (`Sirius A` & 地球大小白矮星 `Sirius B`, $R = 5{,}844\text{ km}$)**、**极速扁球星织女星 (`Vega`, 扁率 $17\%$ 与冯·蔡佩尔重力昏暗 + 冰晶残骸盘)**、**蟹状星云与脉冲星 (`M1 / SN 1054` & `PSR B0531+21` 磁层灯塔)**、**猎户座大星云 (`M42` 惠更斯电离碗、四合星团与哈勃泪滴原行星盘 `Proplyds`)**、**鹰状星云“创生之柱” (`M16 Pillars of Creation`, `4.5 / 3.2 / 1.95 ly` 三维冷分子暗尘埃巨柱)**。
3. **大小麦哲伦星系与麦哲伦星桥**：
   - **大麦哲伦星系 (`LMC`, `16.17 万 ly`)**：偏心金黄恒星棒、单侧旋臂、千光年 **蜘蛛星云 (`30 Doradus`)**、极超巨星 **`R136a1`**（$40\,R_\odot, 46{,}000\text{ K}$）、哈勃/韦布 1:1 **`SN 1987A` 超新星三环沙漏与 24 颗激波珍珠链**、`N11` / `N44` 超级气泡。
   - **小麦哲伦星系 (`SMC`, `20.37 万 ly`)**：视线方向 2.2 万光年三维雪茄状潮汐拉伸、东侧星翼 (`NGC 602`)、翡翠玫瑰色育星暴区 **`NGC 346`** 与激波三星 **`HD 5980`**、7.5 万光年三维**麦哲伦星桥/星流**及前景金核球状星团**杜鹃座 47 (`47 Tucanae`)**。
4. **完整本星系群与仙女座大星系群 (`M31` / `M33`)**：
